修正上下文占用统计的几处计算问题，并在图例中补上「空闲」一项。

## 新增

- 上下文图例新增「空闲」一行，显示容量中尚未被占用的部分，各行因此合起来覆盖整个容量，读者不必再从别处做减法 (af8cf211c)

## 修复

- 重启后继续对话时，上下文占用不再先显示折叠前的旧大小、几轮后才落回真实值。此前换会话与加载折叠摘要是两步，期间的读数会看到完整历史 (3408674e8)
- 折叠摘要不再被算作「系统提示」。系统提示是每轮固定下发的指令，摘要是被折叠的历史，二者体量随对话变化的规律相反；现在摘要单列一类「折叠历史」 (34cb8a530)
- 宿主注入的运行时内容（当前日期、可用技能、执行策略等）不再算作「你的输入」。此前只有一个块被单独归类，其余都记在了用户名下：一句话的提问配上很长的技能目录时，目录被当成了用户说的话 (cd3b5d45d)
- 中文会话的数值不再偏低约三分之一。此前所有文本都按「四字节一个 token」估算，而一个汉字是三字节、约 0.6 个 token；现在按文字种类分别计价，各类别合计与「已使用」严格相等 (cd3b5d45d)

## 升级须知

- 中文会话的自动压缩会比以前更早触发。此前中文占用被低估，`compact_ratio` 设成 90% 时实际要到接近满窗才压缩；修正后压缩点回到设定的比例

Fixes several problems in how context usage was counted, and adds an Idle entry to the legend.

## New

- The context legend gains an Idle row for the capacity a session has not used yet, so the rows cover the whole capacity instead of stopping at what is taken (af8cf211c)

## Fixed

- Continuing a conversation after a restart no longer reports the pre-fold size for a round or three before settling on the real one. Swapping the conversation and adopting its fold were two steps, and a read landing between them saw the whole transcript (3408674e8)
- A compaction digest is no longer counted as the system prompt. The system prompt is the instructions sent every round; a digest is the history that was folded, and the two move in opposite directions as a conversation grows. A digest now has its own Folded history class (34cb8a530)
- Runtime context the host injects — the date, the skill catalogue, the execution policy — is no longer counted as what you typed. Only one such block had a class of its own, so the rest landed in the user figure: a one-line question beside a long catalogue reported the catalogue as yours (cd3b5d45d)
- Chinese text is no longer undercounted by about a third. Everything was priced at four bytes per token, while one han rune is three bytes and roughly 0.6 tokens; strings are now priced by their script, and the classes add up to the usage figure exactly (cd3b5d45d)

## Upgrade notes

- Automatic compaction fires earlier for Chinese conversations. Their usage used to be undercounted, so a `compact_ratio` of 90% folded close to a full window; it now folds where the configured share says
