修复通过 HTTP 添加的 MCP 服务器在握手阶段报「MCP session expired」而无法连接的问题。

## 修复

- 添加以 `http://` 或 `https://` 地址接入的 MCP 服务器时，不再因为服务器在被拒绝的探测请求上下发了 session id 而握手失败。此前这类服务器会报 `MCP startup initialize failed ... http 404: MCP session expired`，例如 mcp-for-unity 的 `http://127.0.0.1:8080/mcp`（新测试 `TestAFailedAnswerDoesNotIssueASession`）

## 升级须知

- 已配置但一直连不上的 HTTP MCP 服务器，升级后重启会话即可自动连接，无需重新添加

Fixes HTTP MCP servers failing the handshake with "MCP session expired" and never connecting.

## Fixed

- Adding an MCP server over an `http://` or `https://` address no longer fails the handshake because the server issued a session id on a refused probe request. Such servers used to report `MCP startup initialize failed ... http 404: MCP session expired`, mcp-for-unity's `http://127.0.0.1:8080/mcp` among them (new test `TestAFailedAnswerDoesNotIssueASession`)

## Upgrade notes

- An HTTP MCP server that is configured but never connected connects on its own after upgrading and restarting the session; no need to add it again
